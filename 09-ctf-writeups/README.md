# CTF Writeups

Writeups from CTF challenges and practice platforms (TryHackMe, Hack The Box, picoCTF, etc.), organized to reinforce hands-on skills alongside the reference notes elsewhere in this repo.

## Suggested writeup format

Create one file per challenge/room: `platform-challenge-name.md`

```markdown
# [Platform] — [Challenge Name]

**Category:** Web / Forensics / Crypto / Network / Reversing / Pwn / OSINT
**Difficulty:**
**Date completed:**

## Objective
What the challenge asked for.

## Recon / Enumeration
Tools and commands used, what was found.

## Exploitation / Solution Path
Step-by-step walkthrough of how the flag was found.

## Flag
`FLAG{...}` (only for platforms where sharing is permitted — check platform rules)

## Lessons Learned
What concept this reinforced, what to remember for next time.
```
